# モバイル環境からのCodexタスク操作とRelay運用

## 概要と前提条件

ChatGPTスマホアプリのCodex（旧称Remote）から、接続中のMacまたはWSLタスクを開いて操作する。本機能は通常のChatGPTクラウド会話にローカルスキルを導入する仕組みではなく、通常のChatGPT会話にはローカルスキルは適用されない。接続先となるMacまたはWSLのPCが起動し、オンライン状態でCodexタスクに接続している必要がある。

公式の仕様および関連資料は、以下のリンクを参照する。

- モバイルアプリの仕様: https://learn.chatgpt.com/docs/mobile
- スラッシュコマンドの仕様: https://learn.chatgpt.com/docs/reference/slash-commands

### 既存ツールおよび設定との関係

Kanaryは本人の希望により既に削除済みである。ただし、Kanaryが提供していた音声入力（Voice）およびキーボード入力（Keyboard）の機能は、本スキルでは代替していない。

また、既存の`docs/commands.md`に記載されている設定例は旧デスクトップ環境向けのものであり、本スキル（relay）との二重登録を避ける必要がある。重複して登録するとコマンドの競合を招くためである。なお、Macのメニューバーを開く`scripts/relay.mjs`は従来のデスクトップ用途であり、本スキルのモバイル実行経路とは別系統として扱う。

## インストールと指示ファイルの更新

本スキルの実行には、Python 3の実行環境と、対象CLIにおけるサブスクリプションへのログインが必要となる。追加のPythonパッケージを導入する必要はない。

インストールの手順は以下のとおりである。

1. 本リポジトリの`skills/relay`を、個人用スキルの正本ディレクトリへ配置する。この配置手順はMacとWSLで共通である。
2. 既存の`skill-sync`を実行してスキルを反映する。
3. 他のユーザーが導入する場合は、各自のスキルディレクトリへ`skills/relay`を配置する。

スキルの反映後、各ホスト（MacおよびWSLの各環境）でポリシー適用スクリプトを実行し、指示ファイルへ共通手順の参照を追加する。

```bash
python3 <skill>/scripts/install_policy.py --apply
```

このコマンドを実行すると、`~/.codex/AGENTS.md`および`~/.claude/CLAUDE.md`へ共通手順の参照が追加される。`--apply`を付けずに実行した場合は、適用要否の確認のみを行う。

スクリプトは既存の旧レビュー文のみを移行し、未知の旧文を検出した場合は処理を停止する。無関係な設定内容はそのまま保持され、更新前のバックアップは`~/.local/state/glass-relay/instruction-backups/`に保存される。

なお、既に開いているチャットセッションには更新が自動で反映されない。反映させるには、新しい会話を開始するか、relayスキルを読み直す必要がある。

## スキルの起動と操作方法

スマホアプリ内のチャット画面で`/relay`を入力してスキルを起動する。

ただし、スマホ実機におけるスラッシュコマンド候補の表示動作は未確認である。実機で候補が表示されない場合や未知のコマンドとして認識された場合は、先頭記号を変更して`$relay`と入力するか、「relayスキルで、この回答をClaudeにレビューして」と指示文を直接送信する。

引数や本文を伴わない単体の`/relay`は、現在の作業に対する新規相互レビューを基本動作とする。レビュー対象が明確である場合は、送り先を尋ねる不要な質問を行わずに処理を進める。

既存会話への送信は新規相互レビューとは異なる操作であり、宛先と原文範囲を作業者本人が指定して確認する。既存のCodex会話を対象とする場合は、利用可能なアプリ内ツールを用いて一覧取得、送信、および返信の確認を行う。なお、既存のClaude会話への直接送信には対応していない。

## レビューの実行仕様と共通手順

本スキルによるレビューは、読み取り専用の一時セッションとして実行される。元の会話コンテキストを変更せずに維持したまま、外部モデルからのレビュー結果を取得できる。共通手順の正本は`skills/relay/references/review-flow.md`に置かれている。

実行経路と使用モデルは、MacおよびWSL環境で共通であり、以下の組み合わせとなる。

- 親Codex環境: Claude Opus 5.5 Mediumを使用する。
- 親Claude Code環境: Codex GPT 6.1 Sol Mediumを使用する。

### 自動起動の条件

レビューは、基本設計や実装方針の策定、新規コードの作成、および大きな改修を行う場合に自動で起動する。微修正のみを行う作業では自動起動しない。

### 共通レビュー手順と判定規則

自動起動によるレビューと`/relay`による手動レビューの双方は、以下の共通手順に従って処理する。

1. 外部モデルによるレビューを実行する。
2. 元のAIがコード原文と指摘内容を照合し、説明を提示する。
3. 作業者本人が指摘ごとに「修正する」「詳しい説明を聞く」「今回は見送る」のいずれかを選択する。
4. 選択された指摘の範囲に限り、修正および検証を実施する。

指摘への対応にあたっては、以下の規則を厳密に適用する。

- **修正許可の成立条件**: 「詳しい説明を聞く」「今回は見送る」の選択、および無回答の状態は、修正を許可したことにはならない。修正の実行には、対象の指摘に対する明示的な承認を必要とする。
- **重複質問の抑止**: 既に同じ指摘と同じ修正範囲を作業者本人が承認している場合は、重複して確認質問を行わない。
- **指摘なし時の処理**: 指摘事項が存在しない場合は、無理に選択肢を作成しない。
- **見送り状態のスコープ**: 「今回は見送る」を選択した記録は同一チャット内でのみ管理され、別チャットへ自動的に共有されることはない。
- **原文欠落時の停止**: 処理対象の原文テキストが取得できない場合は、内容を推測して補完せず、欠落している事実を伝えて停止する。

## 制限事項とエラー処理

本機能は外部サービスの契約枠内で動作し、意図しない課金やループ処理を防ぐ制限を設けている。

- **利用枠と課金**: Relayスキル独自の回数制限は設けていないが、接続先AIサービスの契約枠を消費する。利用枠を超過した場合でも、有料API課金へ自動的に切り替わることはない。
- **通信制御**: モデル間の無限往復処理や、失敗時の自動再送処理は実装されていない。
- **停止条件**: 認証エラー、指定モデルのエラー、または利用枠の上限エラーが発生した時点で、処理は停止する。
