# モバイル環境からのCodexタスク操作とRelay運用

## 概要と前提条件

ChatGPTスマホアプリのCodex（旧称Remote）から、接続中のMacまたはWSLタスクを開いて操作する。本機能は、通常のChatGPT会話にローカルスキルを導入する仕組みではない。接続先となるMacまたはWSLのPCが起動し、オンライン状態でCodexタスクに接続している必要がある。

公式の仕様および関連資料は、以下のリンクを参照する。

- モバイルアプリの仕様: https://learn.chatgpt.com/docs/mobile
- スラッシュコマンドの仕様: https://learn.chatgpt.com/docs/reference/slash-commands

### 既存ツールおよび設定との関係

既存の連携機能であるKanaryは削除せず、スマホ実機での往復動作を確認できるまでは環境に残す。Kanaryが提供する音声入力（Voice）およびキーボード入力（Keyboard）の機能は、本スキルでは代替していないためである。

また、既存の`docs/commands.md`に記載されている設定例は旧デスクトップ環境向けのものであり、本スキル（relay）との二重登録を避ける必要がある。重複して登録するとコマンドの競合を招くためである。なお、Macのメニューバーを開く`scripts/relay.mjs`は従来のデスクトップ用途であり、本スキルのモバイル実行経路とは別系統として扱う。

## インストールと依存環境

本スキルの実行には、Python 3の実行環境と、対象CLIにおけるサブスクリプションへのログインが必要となる。追加のPythonパッケージを導入する必要はない。

インストールの手順は以下のとおりである。

1. 本リポジトリの`skills/relay`を、個人用スキルの正本ディレクトリへ配置する。この配置手順はMacとWSLで共通である。
2. 既存の`skill-sync`を実行してスキルを反映する。
3. 他のユーザーが導入する場合は、各自のスキルディレクトリへ`skills/relay`を配置する。

## スキルの起動と操作方法

スマホアプリ内のチャット画面で`/relay`を入力してスキルを起動する。

ただし、スマホ実機におけるスラッシュコマンド候補の表示動作は未検証である。実機で候補が表示されない場合や未知のコマンドとして認識された場合は、先頭記号を変更して`$relay`と入力するか、「relayスキルで、この回答をClaudeにレビューして」と指示文を直接送信する。

引数や本文を伴わない単体の`/relay`を入力しただけで、他会話へ勝手にテキストが送信されることはない。送り先の指定とレビュー対象の範囲は、チャット内の対話を通じて選択する。

既存のCodex会話を対象とする場合は、利用可能なアプリ内ツールを用いて一覧取得、送信、および返信の確認を行う。

## レビューの実行仕様

本スキルによるレビューは、読み取り専用の一時セッションとして実行される。元の会話コンテキストを変更せずに維持したまま、外部モデルからのレビュー結果を取得できる。

実行経路と使用モデルは以下の組み合わせとなる。

- 新規Claudeレビュー: Opus 5.5 Mediumを使用する。
- 逆方向の新規Codexレビュー: GPT 6.1 Sol Mediumを使用する。

本セッションは新規レビューの立ち上げのみを対象としており、既存のClaude会話への直接送信には対応していない。また、処理対象の原文テキストが取得できない場合は、内容を推測して補完せず、欠落している事実を伝えて停止する。

## 制限事項とエラー処理

本機能は外部サービスの契約枠内で動作し、意図しない課金やループ処理を防ぐ制限を設けている。

- **利用枠と課金**: Relayスキル独自の回数制限は設けていないが、接続先AIサービスの契約枠を消費する。利用枠を超過した場合でも、有料API課金へ自動的に切り替わることはない。
- **通信制御**: モデル間の無限往復処理や、失敗時の自動再送処理は実装されていない。
- **停止条件**: 認証エラー、指定モデルのエラー、または利用枠の上限エラーが発生した時点で、処理は停止する。
