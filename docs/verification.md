## WSLの直接送信

既存Codexデーモン0.160.0のUnix socketへWebSocket/RPCで接続。新しい書き手として既存会話をresumeする方式は使用していない。

既存の作業会話を変更せず、専用のephemeral・read-onlyテスト会話に合成のRelay本文を送信。対象threadのitem/completed(userMessage)で原文の完全一致を確認した。最終結果は`confirmed: true`。

最初の検証ではephemeral会話がthread/turns/listとincludeTurnsに非対応であることを検出し、イベントによる受領確認を追加して再検証した。最初の未確認結果を成功として数えていない。

## 独立レビュー

設計・実装をClaude CodeのOpus 5.5 Mediumで読み取り専用レビュー。レビュー子セッションは非永続、モデルの代替なし。

実装レビューで指摘されたコピー後の二重送信、note-onlyアンカー、範囲未選択、unknownの手動解消、古いCLI要求、Cookie衝突、Macの編集メニュー等を修正した。クラッシュ復元と非公開ディレクトリ除外は既存実装・テストと照合した。

最終差分レビューの未確定カーソル同士の重複、preflight中のアンカー変更を追加で防止し、回帰テストを追加した。旧保存先は存在せず、今回が初回公開のため移行元台帳はないことを確認した。

GitHub初回CIでは、ビルド前にHTTP統合テストを実行して静的入口が404になる順序不備を検出。ビルド→テストを行う`npm run check`へ修正した。macOSビルドの初回CIは合格。

## v0.1.1

Claude CLIのget_usage制御要求による取得を追加。AIのuser入力は送らない。session/weekly_allの明示的なpercentを使い、streamイベントの0–1利用率と混同しない。集計済みの利用枠フィールドだけを返す。スクリプトは非永続・ツールなし・MCPなし・safe-modeで実行する。サービスは60秒ごとに観測を更新する。
